# Portfólio de Quality Assurance (QA)

Portfólio de projetos práticos desenvolvidos durante a formação em **Quality Assurance (QA) na EBAC**. Os repositórios demonstram exercícios e práticas de automação de testes, validação de APIs, testes de performance, bancos de dados, CI/CD e containers.

## Projetos por área

### Automação de testes de interface (UI)

- [Cypress — projeto-base / Hub de Leitura](https://github.com/Nickgdm/teste-cy-base) — aplicação de apoio para praticar QA.
- [Hub de Leitura — testes de UI](https://github.com/Nickgdm/hub-de-leitura-teste-ui) — automação de interface com Cypress.
- [Hub de Leitura — tarefa de testes de UI](https://github.com/Nickgdm/Atividade-hub-de-leitura-teste-ui-task) — atividade prática de testes de interface.
- [Cypress — Intercept e App Actions](https://github.com/Nickgdm/Atividade-Intercept-AppActions-cypress) — recursos avançados de automação de UI.
- [Cypress com Cucumber](https://github.com/Nickgdm/Atividade-cucumber-cypress) — automação orientada a comportamento (BDD).

### Testes de API

- [Testes de API — coleção Postman](https://github.com/Nickgdm/atividade-API-Ebac) — coleção e ambiente para testar a API do catálogo de livros.
- [Hub de Leitura — testes de API com Cypress](https://github.com/Nickgdm/hub-de-leitura-api-teste) — automação de testes de API.
- [Hub de Leitura — tarefa de testes de API](https://github.com/Nickgdm/hub-de-leitura-api-teste-task) — atividade prática de testes de API REST.

### Testes de performance

- [Hub de Leitura — performance com k6](https://github.com/Nickgdm/atividade-k6) — cenários de carga e estresse.
- [BlazeDemo — performance com JMeter](https://github.com/Nickgdm/atividade-jmeter-blazedemo) — plano de teste JMeter e massa de dados.

### Automação mobile

- [Appium e WebdriverIO](https://github.com/Nickgdm/atividade-appium-wdio) — automação mobile Android, incluindo cenário de Drag and Drop.

### CI/CD e DevOps

- [Pipeline de testes com Jenkins](https://github.com/Nickgdm/ci-cd-teste-jenkins) — configuração de pipeline com Jenkins.
- [Exemplo de CI/CD para testes](https://github.com/Nickgdm/atividade-ci-cd-teste-exemplo) — projeto com arquivos de pipeline e Docker.

### Containers

- [Docker — Golden Movie Studio](https://github.com/Nickgdm/atividade-docker) — aplicação e testes organizados com Docker Compose.
- [Docker — Hub de Leitura](https://github.com/Nickgdm/atividade-docker-hub-de-leitura) — ambiente integrado para o Hub de Leitura.

### JavaScript e bancos de dados

- [Testes unitários com JavaScript](https://github.com/Nickgdm/atividade-exercicio-js) — testes com Jest e cobertura de código.
- [Exercícios de SQL](https://github.com/Nickgdm/atividade-SQL) — consultas SQL.
- [Consultas MongoDB / NoSQL](https://github.com/Nickgdm/atividade-NoSQL) — consultas com dados de estudantes e professores.

### Git e atividades complementares

- [Prática de Git — EBAC](https://github.com/Nickgdm/aula-git-ebac) — exercício de versionamento e edição de arquivo.
- [Exercícios BDD — EBAC](https://github.com/Nickgdm/Ebac) — arquivos de funcionalidades Gherkin.

## Tecnologias e ferramentas

Conforme o projeto, o portfólio inclui JavaScript, Node.js, Jest, Cypress, Postman, Appium, WebdriverIO, Cucumber, k6, Apache JMeter, SQL, MongoDB, Docker, Docker Compose e Jenkins.

## Como explorar os projetos

1. Acesse o repositório desejado pelos links acima.
2. Leia o README individual para conhecer o objetivo, os pré-requisitos e os comandos de execução.
3. Consulte os arquivos de teste, configurações e evidências disponíveis.
4. Siga as instruções específicas do projeto para instalar dependências e executar os testes.

## Estrutura do portfólio

```text
Portfólio QA
├── Projetos
│   ├── Automação Web
│   ├── Automação de API
│   ├── Testes de Unidade
│   ├── Testes de Performance

```

As categorias representam a organização lógica dos repositórios neste portfólio; cada projeto permanece em seu próprio repositório GitHub.

## Desafios práticos

As atividades incluem exercitar diferentes tipos de teste, parametrizar dados, configurar ambientes, interpretar resultados e documentar procedimentos de execução. Os detalhes de cada desafio estão descritos no README do respectivo repositório.

## Boas práticas adotadas

- Separação dos projetos por área técnica.
- Documentação de objetivos, ferramentas e instruções de execução.
- Uso de versionamento Git e links para os repositórios individuais.
- Registro de evidências quando disponíveis.
- Descrição dos escopos sem presumir resultados não verificados.

## 📚 Aprendizados

A organização deste portfólio ajuda a consolidar práticas de automação web e de API, testes unitários, performance, automação mobile, bancos de dados, containers e CI/CD. Também reforça a importância de documentar os objetivos, pré-requisitos, cenários e formas de execução de cada projeto.

## Considerações finais

Este portfólio reúne atividades práticas desenvolvidas ao longo da formação em QA. Consulte cada repositório para verificar sua implementação, seus requisitos e suas instruções específicas.
